# Linux Dotfiles

Configurações do meu ambiente Linux.

## Programas

- Fish
- Kitty
- Starship
- Fastfetch
- Plasma
- Niri
- Waybar
- Nvim

## Scripts

- backup.sh — copia as configurações atuais para este repositório.
- install.sh — restaura as configurações em uma nova instalação.

## Estrutura

Cada diretório corresponde às configurações de um programa específico.
